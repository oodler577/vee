vee 2.0 revives the small, portable command-line weblog and Gopher phlog publisher with dependable input handling, tested post management, and user-local installation. The runtime remains shell; Perl is used only for development tests.

## Install without root access

Download the attached `install.sh`, then run:

```sh
sh install.sh
```

Or download it directly:

```sh
curl -fsSL https://github.com/oodler577/vee/releases/download/v2.0/install.sh -o install.sh
sh install.sh
```

The default destination is `~/.local/bin`. Use `--prefix "$HOME"` for `~/bin`, or choose another writable prefix. The script prints the PATH setting when needed. Standalone installation uses curl or wget to fetch the pinned, tested 2.0 runtime; Git and Perl are not required.

The attached `uninstall.sh` uses the same default and `--prefix` option:

```sh
sh uninstall.sh --dry-run
sh uninstall.sh
```

It removes the six commands while preserving blogs, configuration, and unrelated files. Both scripts also work from the source checkout. GitHub's automatic source ZIP and tar.gz downloads include the full project, examples, documentation, and test suite.

## Changes

- Add a core-Perl regression suite runnable with `prove -lr t`, plus seeded input, concurrency, and interruption tests with `prove -lr t xt`.
- Test Linux under dash, bash, and BusyBox ash, actual Alpine/BusyBox userland, native macOS, and a FreeBSD VM. Run ShellCheck and syntax checks.
- Preserve piped input, including backslashes, blank lines, and an unterminated final line.
- Report editor, formatter, and hook failures with nonzero exit status.
- Stage output writes, lock concurrent writers, and retain failed drafts where possible.
- Repair metadata/body extraction, numeric listing, paths containing spaces, configuration precedence, editing, and rebuilding.
- Regenerate Gopher maps reliably and refresh edited titles.
- Restrict purge to known post files and reject destructive extension collisions.
- Recursively deploy publication directories and preserve Gopher symlinks in the optional rsync/SSH helper.
- Repair optional custom formatter examples and format Perl files with `perltidy -l 500`.
- Add user-local installation/uninstallation and comprehensive documentation.

## Compatibility and recovery

Existing raw post filenames and six-line metadata headers remain supported. Back up valuable blogs before bulk rebuilding. Publication is staged per file rather than transactional across the entire site. Failed operations may leave recoverable sources or some completed output; read the error before retrying.

The default formatter selects groff, then fmt, then fold according to availability. Choose an explicit formatter for consistent presentation. Executable hooks receive `html` or `gopher`; templates are literal files. Raw source is intentionally public in the default web layout. The upload helper excludes config, recovery, locks, and Git metadata, but does not delete remote-only files.
